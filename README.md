# SecureFlow: Візуалізатор шляхів атаки та захисту у вебзастосунках

## Команда
- Костюк Поліна
- Владислава Штомпіль

## Опис

SecureFlow — це інтерактивна платформа для моделювання загроз і візуалізації кібератак у вебзастосунках.

- Проблематика: Розробники часто не розуміють у реальному часі, на якому 
саме етапі ланцюга компрометації спрацьовує певний захисний механізм.
- Призначення: Застосунок створений для студентів, викладачів та junior-розробників, 
щоб наочно демонструвати життєвий цикл атак (на основі OWASP Top 10) та те, 
як засоби безпеки розривають цей ланцюг.

## Ролі

- Гість (Guest): Перегляд загальної бази вразливостей, 
публічних кейсів та статичних схем атак.
- Користувач / Студент (User): Доступ до інтерактивної пісочниці,
запуск симуляцій атак, зміна параметрів захисту (вмикання/вимикання валідації чи параметризації).
- Адміністратор (Admin): Управління базою сценаріїв загроз, 
перегляд логів безпеки, налаштування інтеграцій сповіщень.

## Основний функціонал

- Модуль симуляції атак: Покроковий розбір векторів 
(наприклад, SQL Injection, XSS, Broken Access Control) у вигляді інтерактивного графа.
- Інтерактивні бар'єри захисту: Перемикання між «уразливим» і «безпечним» режимами
коду в реальному часі з миттєвою візуалізацією розриву ланцюга атаки.
- Система автентифікації (JWT): Безпечний вхід, видача токенів та перевірка 
прав доступу залежно від ролі.
- Реляційна база даних (PostgreSQL / MySQL): Зберігання користувачів, 
логів атак, сценаріїв та конфігурацій захисту.

## Особливість проєкту
- Інтеграція з Discord-ботом (SecureFlowAlertBot) та нотифікації в реальному часі:
Застосунок генерує автоматичні системні сповіщення у спеціальний канал Discord щоразу, 
коли симулятор фіксує критичну спробу обходу захисту або успішне блокування ланцюга атаки.
- Технічна реалізація: Поєднання бекенду (наприклад, Node.js / Python) із Discord Webhook
/ Bot API для миттєвої доставки подій безпеки команді.
